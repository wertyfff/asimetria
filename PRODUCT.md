# Асиметрия

Fashion storefront concept. Brand name supplied by user: «Асиметрия». WRONGFORM is the collection and hero lettering. Primary action: explore collection, select size, add to a local demonstration bag. Payments and real order fulfilment are not configured.

## Platform
Web, desktop and mobile. Existing buildless HTML/CSS/JS in dist. Sites project identity lives in .openai/hosting.json.

## User commitments
Minimalism. Huge type with a model crossing its boundaries. Clearly visible letter separation on pointer movement. Native scroll transforms an orderly product grid into a chaotic composition and back into the same grid. Reset to top on refresh. Respect reduced motion. Never invent product claims. User dislikes account identifier in the hosting URL; cannot resolve by renaming storefront.
