Project title:
Asimetria / WRONGFORM — Fashion E-commerce

Description:
A distinctive fashion storefront built around oversized typography, asymmetrical clothing and native-scroll interaction. The project covers art direction, interface design, front-end development, mobile refinement, image preparation and English localization.

The experience pairs a precisely aligned loading transition with an expressive collection grid, responsive product imagery, size selection and a persistent shopping bag. Built with HTML, CSS and JavaScript. Independent concept project.
